Pixelcade Sidekick Web Flasher

Flash official Pixelcade Sidekick firmware directly from your browser over USB — no software install required. This is a backup option for machines that can't run the Sidekick desktop flasher tool in Companion; if that already works for you, keep using it.

IMPORTANT: if you're flashing from the same computer that Pixelcade is installed on, you must quit Pixelcade (pixelweb) first. Pixelcade's background Sidekick scanner keeps probing every USB serial port and will conflict with the flasher's connection, causing the flash to fail or corrupt partway through.
Requires Chrome or Edge on desktop (Web Serial API — not supported in Safari, Firefox, or any mobile browser). Connect your Sidekick display over USB, find your board below (compare it with the photos — tap one to enlarge it), and click Flash.

Not sure which board you have? Picking the wrong entry costs nothing but a re-flash — it can't damage the hardware. If the screen stays blank, shows a garbled image, or touch doesn't respond, you likely picked the wrong one; just flash the matching one instead. The 4.3″, 5″, 7″ and 10.1″ sizes each have several genuinely different boards — different panel driver or touch controller wiring — so check your unit against the photos and markings above rather than guessing.
Flashing fails or gets stuck at “Connecting…”? Some boards (particularly native-USB ones) need a manual boot-mode entry: unplug the display, hold its BOOT button, plug it back in while still holding BOOT, then click Flash and release the button once flashing starts.
