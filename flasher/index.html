Pixelcade Sidekick Web Flasher

Flash official Pixelcade Sidekick firmware directly from your browser over USB — no software install required. This is a backup option for machines that can't run the Sidekick desktop flasher tool in Companion; if that already works for you, keep using it.

Requires Chrome or Edge on desktop (Web Serial API — not supported in Safari, Firefox, or any mobile browser). Connect your Sidekick display over USB, pick the matching board below, and click Connect.

800×480, capacitive touch. Two genuinely different boards ship under this size — check your unit's silkscreen and pick the matching one below.

ESP32-8048S070C (Elecrow)

Silkscreen ends in “C” — Elecrow CrowPanel 7.0 / IoTeikXgo.

ESP32-8048S070 (Sunton)

Silkscreen has no trailing “C” — Sunton / EC Buying ESP32-S3 7.0.

Not sure which board you have? For every size except 7″, picking the wrong entry costs nothing but a re-flash — it can't damage the hardware. If the screen stays blank, shows a garbled image, or touch doesn't respond, you likely picked the wrong one; just flash the matching one instead. The two 7″ boards are the one exception — they're different hardware (different pixel-clock pin, timing, and touch wiring), so check the silkscreen above rather than guessing.
Flashing fails or gets stuck at “Connecting…”? Some boards (particularly native-USB ones) need a manual boot-mode entry: unplug the display, hold its BOOT button, plug it back in while still holding BOOT, then click Connect and release the button once flashing starts.
